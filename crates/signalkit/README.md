# signalkit

Umbrella crate: re-exports [`signalkit-core`](https://crates.io/crates/signalkit-core)
(engine: subjects/observations store, clamped velocity, source trait,
injectable time) and [`signalkit-integrity`](https://crates.io/crates/signalkit-integrity)
(fork-ratio verdicts, org-burst detection, robust velocity outliers).

```sh
cargo add signalkit
```

See the [workspace README](https://github.com/WyattAu/signalkit).
